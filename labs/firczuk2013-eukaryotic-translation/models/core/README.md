# Firczuk2013 - Eukaryotic mRNA translation machinery

Firczuk2013 - Eukaryotic mRNA translation machinery This is a model of Saccharomyces cerevisiae mRNA translation which includes the initiation, elongation and termination phases. It can be used to explore generegulation firczuk2013 eukaryotic mrna translation machiner dynamics and compare simulation behavior across conditions.

This core model executes the bundled SBML file in `data/` through `TelluriumSBMLBioModule`. The SBML file remains the scientific source of truth; this wrapper only declares Biosimulant metadata, friendly ports, and traceable mappings.

No public biological inputs are exposed; no source-backed external control was validated for this lab.
